## Projects

### Project 1 · Financial ETL Pipeline
> Extract, transform and load financial data from Yahoo Finance

**What it does:**
- Downloads historical price data for multiple assets simultaneously
- Cleans and validates data quality (nulls, duplicates, outliers)
- Calculates daily returns, cumulative returns and risk metrics
- Exports clean datasets in CSV, Parquet and JSON formats
- Detects outliers (returns > 15%) automatically

**Assets analyzed:** AAPL · MSFT · NVDA · BTC-USD

**Tech stack:** Python · Pandas · NumPy · yfinance
